# 🔎 בוט "מצא לי" לקבוצת מסירות בווטסאפ

הבוט יושב בקבוצת מסירות/מכירות אחת שאתה בוחר. כשמישהו מעלה משהו שאתה מחפש, תוך שניות מגיעה אליך
**התראה בטלגרם עם התמונה המקורית**, הטקסט, ולמה זה מתאים, וכפתור ששולח הודעה למפרסם בווטסאפ.

- **מהיר:** תמונה נבדקת ברגע שהיא עולה, בלי לחכות לטקסט. טקסט שמגיע אחר כך נשלח אליך כהמשך.
- **לא מתבלבל עם מבקשים:** "מחפשת ספה" / "יש למישהו מקרר?" אף פעם לא יגיעו אליך כהתראה.
- **🎯 או 🤔:** כשהוא בטוח 🎯, כשהוא לא בטוח (קופסה סגורה, פריט דומה) 🤔.
- **❌ נמסר:** כשהמפרסם מסמן X על התמונה או מגיב "נמסר" על הפוסט, תקבל עדכון.
- **לומד:** 👍/👎 על כל התראה, והוא מתחשב בזה מעכשיו.
- **רק הקבוצה שבחרת.** לא צ'אטים פרטיים ולא קבוצות אחרות. הוא לא כותב כלום בווטסאפ.

---

## 🚀 הקמה (30–45 דקות, פעם אחת)

צריך מחשב או שרת שדלוק כל הזמן, עם [Node.js](https://nodejs.org) 20 ומעלה.

### 1. התקנה
```bash
cd whatsapp-watcher
npm install
cp .env.example .env
```

### 2. מפתח Claude
ב-[console.anthropic.com](https://console.anthropic.com) → API Keys → צור מפתח, והדבק ב-`.env` בשורה `ANTHROPIC_API_KEY=`.
אפשר להשתמש באותו מפתח של אתר הצעות המחיר.

### 3. בוט טלגרם
1. בטלגרם, פתח צ'אט עם **@BotFather** ושלח `/newbot`.
2. תן שם (למשל "מוצא מסירות") ושם משתמש שנגמר ב-`bot`.
3. העתק את הטוקן שקיבלת ל-`.env` בשורה `TELEGRAM_BOT_TOKEN=`.

### 4. הפעלה ראשונה
```bash
npm start
```
1. יופיע **קוד QR** בטרמינל → בטלפון: ווטסאפ → הגדרות → מכשירים מקושרים → קישור מכשיר → סרוק.
2. בטלגרם, פתח את הבוט שלך ושלח `/start`. הבוט יענה עם ה-**chat id** שלך.
3. הדבק אותו ב-`.env` בשורה `TELEGRAM_CHAT_ID=`, עצור (Ctrl+C) והפעל שוב `npm start`.
   מעכשיו הבוט מקשיב רק לך.

### 5. בחירת הקבוצה והחיפושים (בטלגרם)
```
קבוצות
בחר 3
חפש ספה תלת מושבית עד 800 ש״ח באזור המרכז
חפש אופניים חשמליים
```

### 6. יום ניסיון
ב-`config.js` שנה `dryRun: true`. ההתראות יגיעו עם `[ניסיון]`. לחץ 👍/👎 על כל אחת.
אחרי יום, החזר ל-`false`.

## 💬 פקודות (בטלגרם, בלי סלאש)

| פקודה | מה עושה |
|---|---|
| `חפש <תיאור>` | הוספת חיפוש. תאר כמו לחבר: "עגלת תינוק במצב טוב", "מקרר עד 1000 ש״ח" |
| `רשימה` / `מחק 2` / `מחק הכל` | ניהול החיפושים |
| `קבוצות` / `בחר 3` | בחירת הקבוצה שנסרקת (אחת בלבד) |
| `דוגמאות` / `מחק דוגמה 4` | מה הבוט למד מה-👍/👎 שלך |
| `פספסת 1 ספה פינתית בחולון` | לימוד על משהו שהבוט פספס |
| `השהה` / `המשך` | עצירה וחידוש |
| `סטטוס` | חיבור, קבוצה, מודל והוצאה היום |

**איך הוא לומד:** 👎 → הבוט שואל "למה?" → ענה בקצרה ("רק ספות, לא כורסאות"). מעכשיו כל בדיקה כוללת את זה.

## 🧪 בדיקות

```bash
npm test          # 75 בדיקות, בלי אינטרנט ובלי עלות: קבוצה נכונה, מבקשים, אלבום, נמסר, למידה...
npm run eval      # השוואת מודלים על 38 פוסטים אמיתיים-למחצה (עולה פחות מ-$1)
```

`npm run eval` מריץ כל פוסט ב-`eval/cases/` על Claude Haiku ועל Claude Opus ומדפיס טבלה:
**התראות על מבקשים (היעד: 0)**, התראות שווא, פספוסים, זמן תגובה ועלות. בסוף הוא ממליץ על
המודל המהיר ביותר שלא התריע על אף מבקש. מעדכנים את `model` ב-`config.js`.

**להוסיף תמונות אמיתיות (מומלץ מאוד):**
1. שמור 20 תמונות/צילומי מסך מהקבוצה ב-`eval/images/`.
2. העתק את `eval/cases/images.example.json` ל-`eval/cases/images.json` ותאר כל תמונה (מה צפוי).
3. `npm run eval`.

`npm run eval -- --from-feedback` מריץ גם את כל מה שלימדת את הבוט, כדי לוודא ששינוי לא שבר משהו.

## 🖥️ שיהיה דלוק 24/7

```bash
npm install -g pm2
pm2 start src/index.js --name mesirot
pm2 save && pm2 startup
```
pm2 מפעיל מחדש אחרי נפילה או ניתוק. אחרי חזרה, הבוט משלים פוסטים שפוספסו (מסומנים ⏱️ באיחור).

**התראה כשהבוט נופל (מומלץ):** ב-[healthchecks.io](https://healthchecks.io) (חינם) צור check של דקה,
והדבק את הכתובת ב-`.env` בשורה `HEALTHCHECK_URL=`. אם הבוט שותק, תקבל מייל או הודעת טלגרם.
