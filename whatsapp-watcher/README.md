# 🔎 בוט "מצא לי" לקבוצות מסירות ומכירות בווטסאפ

הבוט מתחבר לווטסאפ שלך (כמו ווטסאפ ווב), קורא את ההודעות בקבוצות המסירות/יד שנייה,
וכשעולה משהו שביקשת — שולח לך הודעה ל**"הודעה לעצמי"** עם פרטי הפוסט, שם המפרסם וקישור אליו.

- **חכם:** Claude מבין מילים נרדפות, סלנג, תמונות ותנאים ("עד 800 ש״ח", "באזור המרכז").
- **שקט:** הבוט לא כותב כלום בקבוצות. הוא רק קורא, ושולח הודעות רק אליך.
- **מנוהל מהטלפון:** מוסיפים ומוחקים חיפושים בהודעה לעצמך.

---

## 🚀 הפעלה

### 1. התקנה
צריך [Node.js](https://nodejs.org) גרסה 20 ומעלה.
```bash
cd whatsapp-watcher
npm install
```

### 2. מפתח Claude (מומלץ)
העתק את `.env.example` ל-`.env` והדבק את המפתח מ-[console.anthropic.com](https://console.anthropic.com).
בלי מפתח הבוט עדיין עובד, אבל רק לפי מילות מפתח (פחות מדויק ולא מבין תמונות).

### 3. בחירת קבוצות
ב-`config.js` ערוך את `groups` — מספיק חלק משם הקבוצה (למשל `"מסירות"`).
רשימה ריקה `[]` = כל הקבוצות.

### 4. הפעלה וחיבור
```bash
npm start
```
יופיע קוד QR בטרמינל → בטלפון: **ווטסאפ → הגדרות → מכשירים מקושרים → קישור מכשיר** → סרוק.
זה חד-פעמי; החיבור נשמר בתיקייה `.wwebjs_auth`.

## 💬 שימוש — שלח לעצמך ("הודעה לעצמי")

| פקודה | מה עושה |
|---|---|
| `!חפש ספה תלת מושבית עד 800 ש״ח` | מוסיף חיפוש |
| `!רשימה` | מציג מה הבוט מחפש (עם מספרים) |
| `!מחק 2` / `!מחק הכל` | מוחק חיפוש |
| `!קבוצות` | מציג את הקבוצות שלך ואילו נסרקות |
| `!השהה` / `!המשך` | עוצר ומחדש התראות |
| `!עזרה` | רשימת הפקודות |

**טיפ:** תאר כמו שהיית מסביר לחבר — "עגלת תינוק במצב טוב", "מסך מחשב 27 אינץ'", "כל ריהוט לגינה".

## 🖥️ שיהיה דלוק 24/7

הבוט עובד רק כשהוא רץ. אפשרויות:
- **מחשב בבית שנשאר דלוק** — הכי פשוט. כדי שיעלה מחדש לבד אחרי נפילה:
  ```bash
  npm install -g pm2
  pm2 start src/index.js --name whatsapp-watcher
  pm2 save && pm2 startup
  ```
- **שרת VPS קטן** (Oracle Cloud חינם / Hetzner ~4€ לחודש) — אותן פקודות.

> ⚠️ Render החינמי שבו רץ אתר הצעות המחיר **לא מתאים** כאן: הוא נרדם ומוחק את הדיסק,
> כך שהבוט יפספס הודעות ויבקש לסרוק QR מחדש כל פעם.

## ⚙️ הגדרות נוספות (`config.js`)
- `analyzeImages` — לשלוח ל-Claude גם את התמונות (מומלץ; פוסטים רבים הם תמונה + "למסירה").
- `forwardOriginal` — להעביר אליך גם את ההודעה המקורית עם התמונה.
- `model` / `effort` — המודל וכמה "לחשוב" על כל פוסט.

## 💰 עלות
כל הודעה בקבוצה שנסרקת = בקשה קצרה אחת ל-Claude. בקבוצות עמוסות זה מצטבר —
כדאי לעקוב בהתחלה ב-console.anthropic.com. כשההתראות מושהות (`!השהה`) או שאין חיפושים — אין עלות.

## ⚠️ חשוב לדעת
הבוט משתמש בווטסאפ ווב בצורה לא רשמית (ספריית whatsapp-web.js). וואטסאפ לא מאשרת אוטומציה כזו,
ותיאורטית יש סיכון קטן לחסימה. הבוט מצמצם את הסיכון בכך שהוא לא שולח הודעות לאף אחד חוץ ממך.
אם זה מדאיג אותך — חבר אותו למספר משני (סים נוסף / eSIM) שחבר באותן קבוצות.
